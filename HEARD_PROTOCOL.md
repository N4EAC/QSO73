# Heard query protocol

Prefix `~Q73H:` plus compact version-1 JSON, inside an ordinary AX.25 UI packet. Every message is at most 200 UTF-8 bytes. Required fields: `v=1`, `k=request|reply`, UUID `id`, `w=60` (minutes). Optional `q` is an uppercase AX.25 callsign, preserving an explicit SSID including -0. A missing q asks for recent callsigns. Requests cannot contain h; replies require h, a list of up to three entries (one for q queries), each `[callsign, age_seconds, SNR_tenths_or_null]`. Ages are 0-3600; callsigns are validated and canonicalized. An empty h means no recent callsigns or the queried call was not heard. No sender grid or guessed signal measurement is required.

Replies go to the requester. Incoming replies must match an outgoing request ID, subject and addressed responder (or any responder for QST). A request is correlated for ten minutes; every responder can contribute one reply. Dedup cache: 512 keys; outstanding requests: 16; pending replies: 8. Broadcast reply delay: 4-24 seconds; shared automatic submissions have at least five seconds spacing. Per-requester reply limit: one minute. Busy pending replies expire after two minutes. Auto replies are saved, off by default, and disabling cancels pending replies.

History: successfully decoded AX.25 callsigns, at most 256 callsign/SSID entries, past hour of this modem session. Actual engine metadata provides SNR/time; KISS decoding supplies an unknown-SNR fallback. Old history, unverified PHY IDs and the local callsign/SSID are excluded; a different explicit SSID can be queried. Recent lists collapse SSIDs to the latest record per base call and exclude the requester. Base callsign search matches any SSID; explicit -0 or -n searches exactly. Disconnect clears history/pending/correlation. Ages are computed at reply creation and do not include subsequent queue/airtime. History can span frequencies used during the session.

No delivery acknowledgment, forwarding, Internet lookup or query/reply loop is introduced. Existing channel/direct/ordinary packet formats remain unchanged.
